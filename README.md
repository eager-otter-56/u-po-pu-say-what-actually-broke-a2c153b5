A single-line software error message entry for the make.fun bounty "Say What Actually Broke" — running main.py writes the error line to entry.txt in MAKEFUN_OUTPUT_DIR (default /output). The line names the real failure (an expired security certificate), tells the user what to do next, and admits whose fault it was.
